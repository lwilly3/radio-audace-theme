# Thème Radio Audace

Thème WordPress sur mesure pour [radioaudace.com](https://www.radioaudace.com),
pensé pour une radio d'information : le direct, les émissions et les articles.

**État : en production** sur radioaudace.com (version dans `radio-audace/style.css`).

- `radio-audace/` : le thème
- `design/` : maquettes
- `docs/` : documentation de fonctionnement — [`docs/CONTINU.md`](docs/CONTINU.md) : le fil « Audace en continu »
- `CHANGELOG.md` : versions ; chaque section sert de notes à la release GitHub
- `release.sh` : publie la version courante (c'est la release, pas le push, qui met le site à jour)
- `CLAUDE.md` : contexte, décisions et règles du projet
