# Thème Radio Audace

Thème WordPress sur mesure pour [radioaudace.com](https://www.radioaudace.com),
pensé pour une radio d'information : le direct, les émissions et les articles.

**État : en conception.** La maquette précède l'écriture du thème.

- `radio-audace/` : le thème
- `design/` : maquettes
- `docs/` : documentation de conception
- `CLAUDE.md` : contexte, décisions et règles du projet
